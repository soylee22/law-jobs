# Mithril 2.0: 16 September 2026

## Implemented

Replaced the iframe interface with a single responsive workspace. Added explicit source-health and requirement evidence, combinable filters, search, URL navigation, pagination, source-specific labels, conservative location handling, explicit PQE treatment, stable canonical URL IDs, possible duplicate flags and non-destructive unknown/missing status.

Added local encrypted saved roles, preparation and application stages, interview/offer/rejection/withdrawal states, hidden roles, notes, next-action dates, application history, saved searches, encrypted backups and password-checked restore. Added inactivity lock, decrypted-DOM clearing, stale-tab protection, input escaping, link validation and CSV formula protection.

Migrated public vacancy data only. The old shortlist and other generated pages are redirects in the package. Original detailed candidate narratives and applied markers are not copied into the public snapshot. Historical source history is not rewritten.

Added reusable source templates, a publish-safe import/build script, a guarded installer, unit tests, browser checks, CI and deployment documentation.

## Not claimed

No fresh scan of every job; no repair of an unseen upstream crawler; no verified eligibility model; no synced cloud account; no production deployment through a connector that refused write access; no independent security audit; no erasure of old public disclosures.
